# Pros

## Pros of Open-Source:

To stay brief I have limited this page to 5 pros related to open-source, which are the following: 

1. Transparency 
2. Customization 
3. Community Collaboration 
4. Educational Opportunities
5. Security Benefits
 
From the perspective of students and researchers, transparency is not only helpful for understanding software, but it also supports reproducible science since methods and code can be shared openly. Researchers can customize tools to fit unusual experimental designs, or add a method to an existing function within a library. So an example from my own study would be the Python programming language [1] which is used ubiquitously, and the open-source platform PsychoPy [2] that we use to create and run experiments. These tools help us be transparent, share experiments, and allow others to improve upon our work.

If I imagine someone maintaining a popular Python library, open-source becomes an opportunity for collaborating with experts and an opportunity to develop your skillset, all while gaining some recognition.

Lastly, when it comes to security, as we have seen with the PHP2Shell [3,4] case, open-source means a lot of eyes, and now also AI, can review code for vulnerabilities. This of course means security flaws may be identified and fixed more rapidly.
